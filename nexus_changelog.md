# Changelog

### [v1.3.0]
- Fix: at low master volume the Radioport and the car radio no longer cut out when turned down or when gunfire or the police scanner is heard.
- Fix: choosing a station in the station selection UI applies it once.
- New: optional file Radioport Off, which keeps the Radioport off for good.

### [v1.2.1]
- Game 2.5 support.

### [v1.2.0]
- Fix: the station selection UI now shows the new song when the track changes while it is open on foot. Before, it kept the old song name until you switched station and back.

### [v1.1.0]
- Fix: the Radioport no longer plays quieter and muffled after getting out of a vehicle. Before, it stayed that way until the next save was loaded.
- Now requires Redscript.

### [v1.0.0]
- First release. The Radioport no longer goes silent while a car or a world radio tuned to the same station is nearby.
